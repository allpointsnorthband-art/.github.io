## 1. The 12-Month Release Timeline

### Strategic Principle

## 2. Release Types & When to Use Them

| Release Type | When | Purpose | Spotify Impact |
|---|---|---|---|
| **New single** | Every 4-6 weeks during active release period | Maximum algorithmic push | Enters Release Radar, eligible for editorial |
| **EP / Album** | 1-2 per year | Anchor release, press hook, streaming depth | All tracks enter Release Radar |
| **Live recording** | Between release cycles | Keeps activity going without new studio material | Enters Release Radar as new release |
| **Acoustic/Remix** | Between release cycles | Shows versatility, reaches different audiences | Enters Release Radar |
| **Cover** | Sparingly (1-2/year) | Can attract fans of the original artist | Moderate algorithmic impact |

## 3. The 48-Hour Launch Playbook

This is a step-by-step checklist for the 48 hours surrounding any release. Print this out and follow it exactly.

### 4 Weeks Before Release

- [ ] Upload to DistroKid with release date set (Friday, 8AM EST / 2PM CET)
- [ ] Enable "Leave a Gap" in DistroKid settings
- [ ] Pitch to Spotify editorial via Spotify for Artists (fill every field -- see Spotify Engine guide)
- [ ] Upload lyrics via DistroKid
- [ ] Create Spotify Canvas (3-8 sec looping video)
- [ ] Prepare press email (see Press Outreach guide)
- [ ] Write newsletter draft

### 2 Weeks Before Release

- [ ] Share DistroKid pre-save link on Instagram Stories (3x this week)
- [ ] Post teaser Reel: 15-sec clip of the new track
- [ ] Send newsletter: "New single dropping [Date]"
- [ ] Send press emails to Tier 1 blogs (offer premiere if desired)

### 1 Week Before Release

- [ ] Post teaser Reel #2: different clip, "One week"
- [ ] Instagram Story: countdown sticker
- [ ] Send press emails to Tier 2 blogs
- [ ] Prepare release-day social content (have posts ready to schedule)

### Release Day (Friday)

- [ ] 8:00 AM EST / 2:00 PM CET: Track goes live on Spotify
- [ ] Immediately: Post Instagram Reel with the track as audio. CTA: "Save this track on Spotify"
- [ ] Immediately: Post Instagram Story with Spotify link sticker. "New single out now -- tap to save"
- [ ] 10:00 AM: Send newsletter: "Out now: [Track Name]" with Spotify link
- [ ] 12:00 PM: Post on Facebook with Spotify link
- [ ] 2:00 PM: Post in r/progmetal and r/progrockmusic (if appropriate per community rules)
- [ ] 4:00 PM: Share to any relevant Discord servers / forums
- [ ] 6:00 PM: Instagram Story #2: behind-the-scenes of the track

### Day 2 (Saturday)

- [ ] Morning: Check Spotify for Artists -- monitor saves, streams, skip rate, playlist adds
- [ ] Post Instagram Story: "Thank you for the incredible response" or share a streaming milestone
- [ ] Engage with every comment and DM from release day
- [ ] Submit to SubmitHub (blogs + playlists)
- [ ] Pitch 5-10 independent playlist curators directly

### Day 3-7

- [ ] Continue playlist pitching (5 curators/day)
- [ ] Post 2 more Reels featuring the track (performance clips, gear breakdown)
- [ ] Monitor Spotify for Artists daily: if the track is gaining traction, double down on social posting
- [ ] Reply to any blog/press coverage -- reshare and thank them

### Day 8-30

- [ ] Continue weekly playlist pitching
- [ ] Post 1-2 Reels per week featuring the track
- [ ] Track metrics in Google Sheets: streams, saves, playlist adds, blog placements

## 4. DistroKid Release Scheduling Guide

### Step by Step

1. Log into distrokid.com
2. Click "Upload"
3. Fill in track details:
   - **Artist**: All Points North
   - **Track title**: [Name]
   - **Album / Single**: Single
   - **Genre**: Rock > Progressive Rock
   - **Release date**: Set to a Friday, at least 4 weeks from today
   - **Previously released?**: No (unless re-releasing)
4. Upload audio file (WAV, 16-bit, 44.1kHz recommended)
5. Upload cover art (3000x3000px, JPEG or PNG, <20MB)
6. **Lyrics**: Upload lyrics (Spotify will display them)
7. **Options**:
   - Leave a Gap: ON (ensures track hits Release Radar on release day)
   - YouTube Content ID: OFF (unless you want to claim fan videos)
   - Shazam: ON
8. Review and submit
9. Once processed: copy the pre-save link from DistroKid dashboard

### Pre-Save Links

DistroKid generates a pre-save link automatically. Use this link in all pre-release promotion:
- Instagram bio (via Linktree)
- Instagram Stories
- Newsletter
- Direct messages

Pre-saves directly convert to "saves" on Spotify at release -- the most valuable engagement signal.
