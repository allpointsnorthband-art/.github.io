# Automation Setup -- Free Tools & Weekly Workflow

**Band**: All Points North
**Time budget**: 90 minutes/week
**Budget**: 0 EUR (all free-tier tools)

---

## 1. Tool Stack -- Complete Setup Guide

### Meta Business Suite (Social Scheduling) -- FREE

**What it does**: Schedule Instagram Reels, posts, and Stories. Also auto-shares to Facebook.

**Setup (15 min, one-time):**
1. Ensure Instagram is a Professional Account (Settings > Account > Switch to Professional > Musician/Band)
2. Ensure the Instagram account is connected to the Facebook Page (/apnlive)
3. Download Meta Business Suite app (iOS/Android) or use business.facebook.com
4. Log in with the Facebook account connected to the Instagram
5. You can now create, schedule, and analyze posts for both platforms from one dashboard

**Daily use**: Create content once per week, schedule it all in one session.

---

### Buffer (Cross-Platform Scheduling) -- FREE TIER

**What it does**: Schedule posts across Instagram, Facebook, and one more platform (Twitter/X or LinkedIn). Useful if you expand beyond Instagram.

**Free tier limits**: 3 connected channels, 10 scheduled posts per channel.

**Setup (10 min, one-time):**
1. Go to buffer.com and create a free account
2. Connect Instagram, Facebook, and Twitter/X (if applicable)
3. Install the Buffer browser extension for easy sharing

**Note**: Meta Business Suite handles Instagram+Facebook well on its own. Buffer becomes useful when adding a third platform (Twitter/X, LinkedIn for industry networking).

---

### Mailchimp (Email Newsletter) -- FREE TIER

**What it does**: Manage email subscribers, send newsletters, automate welcome emails.

**Free tier limits**: 500 contacts, 1,000 sends/month, 1 audience.

**Setup (20 min, one-time):**
1. Go to mailchimp.com and create a free account
2. Create an audience: "All Points North Fans"
3. Set default from: allpointsnorth.band@gmail.com
4. Create a signup form (Audience > Signup Forms > Embedded Forms)
5. Copy the embed code for the EPK website
6. Create a landing page with shareable URL (for Instagram bio and QR codes)
7. Set up the automated welcome email (see Fan Community guide)

**Monthly use**: Send one newsletter on the first Tuesday of each month.

---

### Canva (Visual Content) -- FREE TIER

**What it does**: Create graphics for Spotify Canvas, playlist covers, social media posts, one-sheets, and flyers.

**Free tier includes**: 250,000+ templates, 100+ design types, 5GB storage.

**Setup (10 min, one-time):**
1. Go to canva.com and create a free account
2. Create a "Brand Kit" (free version allows limited branding):
   - Upload band logo
   - Set primary colors (from album art / EPK website)
   - Set fonts (match the EPK website style)
3. Create templates for recurring content:
   - Instagram Reel cover (1080x1920)
   - Instagram post (1080x1080)
   - Spotify playlist cover (1600x1600)
   - Spotify Canvas (1080x1920, animated)

**Preset sizes to save:**
| Content Type | Dimensions | Notes |
|---|---|---|
| Instagram Reel | 1080 x 1920 px | 9:16 vertical |
| Instagram Post | 1080 x 1080 px | Square |
| Instagram Story | 1080 x 1920 px | 9:16 vertical |
| Spotify Canvas | 1080 x 1920 px | Export as MP4, 3-8 sec loop |
| Spotify Playlist Cover | 1600 x 1600 px | Square |
| Facebook Cover | 820 x 312 px | Landscape |
| One-sheet (press) | A4 / Letter | PDF export |

### CapCut (Video Editing) -- FREE

**What it does**: Edit short-form video for Reels/TikTok/Shorts. Mobile and desktop app.

**Setup (5 min, one-time):**
1. Download CapCut (iOS/Android/Desktop)
2. No account needed for basic editing
3. Learn 3 key features: Trim, Text Overlay, Audio Replacement

**Weekly use**: Edit 2-3 clips trimmed from rehearsal footage.

---

### Linktree (Bio Link Aggregator) -- FREE TIER

**What it does**: Single link in Instagram bio that expands to multiple destinations.

**Setup (10 min, one-time):**
1. Go to linktr.ee and create a free account
2. Add links in this priority order:
   - Latest release on Spotify (always keep this updated)
   - EPK website
   - Bandcamp
   - Mailing list signup (Mailchimp landing page)
   - YouTube
   - Upcoming shows (when applicable)
3. Set the Linktree URL as your Instagram bio link

**Linktree content:**
```
🎵 Listen to "Embracer" on Spotify
🌐 Electronic Press Kit
🎸 Bandcamp
📧 Join our mailing list
📺 YouTube
🎫 Upcoming shows
```

## 2. The 90-Minute Weekly Workflow

This is the complete weekly routine. Three sessions, 90 minutes total.

### SUNDAY: Content Batch (45 minutes)

| Time | Action | Tool |
|---|---|---|
| 0:00-0:20 | Review footage from the week. Select 2-3 best clips. | Phone camera roll |
| 0:20-0:35 | Edit clips: trim, add text, set audio. | CapCut |
| 0:35-0:45 | Schedule 2 Reels for Tue/Thu + 1 Story for Sat. Write captions. | Meta Business Suite |

**Prep for next Sunday**: At rehearsal during the week, record 3-5 short clips on your phone. Aim for at least one from each format (performance, behind-the-scenes, gear). This takes zero extra time -- just have someone prop up a phone.

### WEDNESDAY: Outreach (30 minutes)

| Time | Action | Tool |
|---|---|---|
| 0:00-0:10 | Find 3-5 new playlists/blogs to pitch. Add to tracker. | Spotify, Google, SubmitHub |
| 0:10-0:25 | Send 3-5 personalized pitch messages. Log in tracker. | Email, Instagram DMs |
| 0:25-0:30 | Reply to any DMs, comments, or emails from the week. | Instagram, Gmail |

### FRIDAY: Check & Engage (15 minutes)

| Time | Action | Tool |
|---|---|---|
| 0:00-0:05 | Check Spotify for Artists: streams, saves, new playlists. | Spotify for Artists app |
| 0:05-0:10 | Quick Instagram engagement: like/comment on 5 peer band posts. | Instagram |
| 0:10-0:15 | Post a quick Story (behind-the-scenes, preview of next week's Reel). | Instagram |

### MONTHLY: Newsletter + Metrics (30 minutes, first Tuesday)

| Time | Action | Tool |
|---|---|---|
| 0:00-0:15 | Write and send monthly newsletter. | Mailchimp |
| 0:15-0:30 | Update metrics tab in Google Sheets. Review what's working. | Google Sheets + Spotify for Artists |

## 3. Automation Cheat Sheet

| Repetitive Task | Automated By | Manual Effort Remaining |
|---|---|---|
| Posting to Instagram | Meta Business Suite (scheduled) | Create content once, schedule for the week |
| Cross-posting to Facebook | Meta Business Suite (auto-share) | Zero -- happens automatically |
| Welcome email to new subscribers | Mailchimp automation | Zero -- runs on autopilot |
| Tracking pitch submissions | Google Sheets template | 2 min per submission (log it) |
| Hashtag sets | Saved presets in Notes app | Paste from preset |
| Bio link management | Linktree | Update when new release drops |
| Spotify profile analytics | Spotify for Artists app alerts | Glance at weekly notification |

## 4. Setup Priority Order

If you only have 1 hour to set everything up, do these in order:

1. **Spotify for Artists** -- claim profile, add Canvas, set Artist Pick (already done? Verify.)
2. **Instagram Professional Account** + **Meta Business Suite** -- enables scheduling
3. **Linktree** -- bio link for Instagram
4. **Google Sheets** -- create tracking spreadsheet with all tabs
5. **Mailchimp** -- email list setup + signup form
6. **Canva** -- brand kit + first playlist cover
7. **CapCut** -- download and learn trim/text/audio (5 min)

Total one-time setup: ~90 minutes.
After setup, weekly maintenance: ~90 minutes.
